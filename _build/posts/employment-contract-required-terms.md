多數中小企業的勞動契約是一張紙：職稱、薪資、到職日、兩邊蓋章。

這張紙在平順的時候完全夠用。**它不夠用的時機，正好是唯一需要它的時機**——有人要走、有人要告、有人要查。

## 一、法定該約定的十三款

《勞動基準法施行細則》第 7 條：勞動契約應依本法有關規定約定下列事項。

| # | 應約定事項 |
|---|---|
| 一 | 工作場所及應從事之工作 |
| 二 | 工作開始與終止之時間、休息時間、休假、例假、休息日、請假及輪班制之換班 |
| 三 | 工資之議定、調整、計算、結算與給付之日期及方法 |
| 四 | 勞動契約之訂定、終止及退休 |
| 五 | 資遣費、退休金、其他津貼及獎金 |
| 六 | 勞工應負擔之膳宿費及工作用具費 |
| 七 | 安全衛生 |
| 八 | 勞工教育及訓練 |
| 九 | 福利 |
| 十 | 災害補償及一般傷病補助 |
| 十一 | 應遵守之紀律 |
| 十二 | 獎懲 |
| 十三 | 其他勞資權利義務有關事項 |

一張紙的契約通常涵蓋第一、三款的一部分，其餘**全部缺漏**。

## 二、漏掉的那幾款，剛好是會吵架的那幾款

把十三款對照實務爭議，模式很清楚：

| 常見爭議 | 對應款次 |
|---|---|
| 「這不是我的工作範圍」 | 一（應從事之工作） |
| 「加班費算錯了」 | 三（工資之計算方法） |
| 「離職要不要給資遣費」 | 四、五 |
| 「工具壞掉要不要賠」 | 六（工作用具費） |
| 「這樣就要記過？」 | 十一、十二（紀律與獎懲） |

> !! **沒寫，不代表沒有義務；只代表發生爭議時沒有依據。**
> 而在工時與工資這兩塊，**留存紀錄的法定義務在雇主身上**——
> 工資清冊（勞基法 §23 II）與出勤紀錄（§30 V）都應**保存五年**。
> 拿不出東西的那一方，通常是公司。

## 三、🔴 「薪資含加班費」是高風險寫法

這是中小企業最常見的一種簡化。

施行細則第 7 條第 3 款要求約定的是**工資之議定、調整、計算、結算與給付之日期及方法**——關鍵在**算得出來**。

把本薪與加班費混成一個總額，會有兩個後果：

1. 爭議時**無法證明**加班費已依勞動基準法第 24 條的費率給足
2. 勞檢時工資清冊**無法呈現各項目計算方式明細**（§23 II 的要求）

✅ 正確做法是**分項列示**：本薪、各項津貼、加班費各自列出，且能從工時紀錄回推驗算。

### 第十三款不是萬用抽屜

「其他勞資權利義務有關事項」看起來包山包海，但**放進去的東西各有各的法定要件**。

最常見的兩種是**競業禁止**與**最低服務年限**——這兩種約定寫在契約裡**不等於有效**：
競業禁止依勞動基準法第 9 條之 1 須同時符合四款要件，**缺一即整條無效**；
最低服務年限依第 15 條之 1 須有專業技術培訓或合理補償，違反者亦屬無效。

⚠️ **無效的條款比沒有條款更糟**——它讓公司誤以為有保護，因此在真正該做的管控上鬆懈。

## 四、兩份文件分工，不要塞進一張紙

把十三款全部塞進個別勞動契約，既難寫也難改——每次制度調整都要重簽全部員工。

實務上可行的分工是：

| 文件 | 寫什麼 | 特性 |
|---|---|---|
| **勞動契約** | **個別條件**：職務、工作場所、工資數額、到職日 | 一人一份，因人而異 |
| **工作規則** | **共通制度**：工時、請假、獎懲、紀律、福利、安全衛生 | 全體適用，一次修改全體生效 |

依勞動基準法第 70 條，**僱用勞工 30 人以上者應訂立工作規則，報請主管機關核備後並公開揭示**。所以 30 人以上的公司本來就要有工作規則——把制度性內容放進去，契約才能維持精簡。

⚠️ 30 人以下沒有這項法定義務，但**制度性內容還是要有地方寫**。可以用「員工手冊」或契約附件的形式處理，重點是**內容存在且員工知悉**。

## 五、一份現有契約的健檢

拿出你現在在用的那份，對著十三款打勾：

- [ ] 一、工作場所與**應從事之工作**寫得具體嗎（不只是職稱）
- [ ] 二、工時、休息、例假、休息日、請假、輪班換班
- [ ] 🔴 三、工資的**計算方法**——加班費是否**分項可驗算**
- [ ] 四、契約訂定、終止及退休
- [ ] 五、資遣費、退休金、津貼、獎金
- [ ] 六、膳宿費與工作用具費（有要員工負擔的才寫，但要寫清楚）
- [ ] 七～十、安全衛生、教育訓練、福利、災害補償與傷病補助
- [ ] 十一、十二、**應遵守之紀律與獎懲**（沒寫就很難懲處）
- [ ] 十三、其他勞資權利義務

打不完的那幾項，就是你目前的風險所在。
