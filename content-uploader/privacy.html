內容上傳工具隱私權政策

資料存取與用途

工具請求 YouTube 影片上傳與唯讀權限，用於上傳、設定影片資訊與縮圖，以及查詢授權頻道、既有影片、公開狀態與排程資訊。Google 登入與同意流程由 Google 官方頁面處理，工具不收集 Google 密碼。

儲存與分享

授權憑證保存在營運者電腦的各頻道憑證資料夾，供後續更新連線；本機排程表及執行日誌可能保存影片標題、說明、路徑、影片 ID、發布時間與處理結果。營運者應保護電腦、限制檔案存取，不應將憑證放入公開儲存庫或筆記。

執行影片上傳與查詢時，必要的資料會傳送至 Google／YouTube；公開內容依使用者設定對外顯示。這些 Google 使用者資料不用於出售、廣告投放或訓練通用 AI 模型。

保留與刪除

憑證保留至營運者撤銷授權或移除本機憑證；本機排程與日誌由營運者依營運需要保留。要停止工具存取，可到 Google 帳戶連結管理撤銷應用程式授權，並移除本機對應憑證。撤銷授權不會自動刪除已上傳至 YouTube 的影片；影片需在 YouTube Studio 管理。

Google 資料使用規範

本工具對 Google API 所取得資訊的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。本工具使用 YouTube API Services；YouTube 亦適用 Google 隱私權政策。
