publish-skill — 隱私政策

Privacy Policy

生效日期 Effective date：2026-08-13

這是什麼 / What this is

publish-skill 是一個個人自用的內容發佈工具，由粉絲專頁的經營者本人在自己的電腦上執行， 用來把自己製作的內容發佈到自己擁有的社群帳號。 它不是對外提供的服務，沒有其他使用者，也不開放任何人註冊或登入。

publish-skill is a personal, self-hosted tool run by the page owner on their own computer to publish their own content to social accounts they own. It is not a public service, has no other users, and offers no sign-up or login to anyone else.

我們收集哪些資料 / Data we collect

不收集任何資料。

  • 不收集造訪本頁面訪客的任何資訊
  • 不收集、讀取或儲存其他使用者的個人資料
  • 本頁面不使用 Cookie、不做流量分析、不嵌入第三方追蹤程式

We collect no data. No information is collected from visitors to this page, no personal data of any other person is collected, read, or stored, and this page uses no cookies, analytics, or third-party trackers.

存取權限的用途 / How access is used

本工具透過官方 API 存取經營者本人擁有的帳號，用途僅限於：

  • 將經營者自行製作的圖片、影片與文案上傳為草稿、排程或已發佈的貼文
  • 讀取這些貼文自身的狀態，以確認上傳是否成功

本工具不讀取粉絲專頁的粉絲名單、訊息內容、留言者個資，也不會對其他使用者採取任何動作。

The tool uses official APIs to access only accounts owned by the operator, solely to upload the operator's own images, videos, and text as drafts, scheduled, or published posts, and to read the status of those posts. It does not read follower lists, message contents, or commenter data, and takes no action affecting other users.

憑證如何保管 / Credential handling

存取權杖僅儲存在經營者本人電腦的環境變數與本機檔案中，不會上傳到任何伺服器、不會傳送給第三方， 也不會出現在本網站上。本網站是純靜態頁面，沒有後端、沒有資料庫。

Access tokens are stored only in environment variables and local files on the operator's own computer. They are never uploaded to any server, never shared with third parties, and never appear on this site. This site is a static page with no backend and no database.

資料分享與保留 / Sharing and retention

沒有資料可以分享，因此不與任何第三方分享資料。工具本身不建立資料庫，也不保留任何個人資料。 已發佈的內容依各平台自身的政策保存，可由經營者隨時於該平台刪除。

There is no data to share, so nothing is shared with any third party. The tool keeps no database and retains no personal data. Published content is retained under each platform's own policy and can be deleted by the operator at any time.

資料刪除 / Data deletion

由於本工具不收集也不保留任何個人資料，沒有可供刪除的資料。 若您認為有任何相關疑慮，請透過下方管道聯絡，我們會盡快處理。

As no personal data is collected or retained, there is no data to delete. If you believe otherwise, please contact us using the channel below and we will respond promptly.

使用的平台 API / Platform APIs used

  • Meta Graph API（Facebook 粉絲專頁、Instagram）
  • YouTube Data API v3

使用方式均遵循各平台的開發者政策與服務條款。
